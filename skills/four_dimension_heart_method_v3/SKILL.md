## 技能描述

> 四维心法v3升级版，包含v1+v2所有内容外加四大维度的完整框架

四维心法（Four-Dimensional Heart Method）是一个融合东方经典智慧的决策思维体系，

## 参数定义

### user_query
- **类型**: string
- **必填**: true
- **描述**: 用户的决策问题、需要分析的事物

### analysis_depth
- **类型**: string  
- **必填**: false
- **默认值**: standard
- **描述**: 分析深度 [standard/advanced/comprehensive]

### time_horizon
- **类型**: string
- **必填**: false
- **默认值**: auto
- **描述**: 时间视野 [short/medium/long/auto]

### system_prompt
- **类型**: string
- **描述**: 可以指定特定的分析框架或角色

## 东方决策六维体系

四维心法v3在v1+v2基础上，正式升级为"东方决策六维体系"。

### 核心四维

1. **阴阳鱼** → 看大局（全局观、周期观、阴阳转化）
2. **上善水** → 找支点（杠杆、边际、最优解）  
3. **仁恕矩** → 通人心（利益链、博弈面、关系网）
4. **中庸行** → 定分寸（时机、节奏、边界）

### 经典来源

四维心法v3的核心经典来源：
- 《大学》
- 《易经》
- 《道德经》
- 《论语》
- 《中庸》

### 总纲

"知止"（《大学》）—— 知道该在哪里停，比知道往哪走更重要

## 决策流程

### 四维罗盘操作流程

1. 问问题 - 用自然语言描述当前困境
2. 阴阳鱼 - 当前局势的阴阳两面是什么？趋势方向？
3. 上善水 - 最大杠杆/最省力点在哪？
4. 仁恕矩 - 各方利益诉求？博弈面？
5. 中庸行 - 当前最佳分寸是什么？
6. 知止 - 该在哪停？边界在哪？

### 输出格式

每一套分析都必须包含：
- **知**：这件事的本质是什么？
- **行**：基于真知，何为恰到好处之行动？
- **证**：用实践结果反验认识
