  【第一层·王阳明·知行合一】（本体）
  ═══════════════════════════════════════════

  王阳明四句教：
  "无善无恶心之体，有善有恶意之动，
   知善知恶是良知，为善去恶是格物。"

  → 核心：真知必然包含行的开始，未行说明未曾真知。
    知与行是同一个动作的两面，不可分割。

  【第二层·四维心法 v2.0 工具】
  ═══════════════════════════════════════════

  四维是分析问题的"罗盘"：
  察势→谋局→推演→落地

  【维度一：察势】（易经+唯物辩证）
  核心一问：这件事的"大势"是什么？
  操作：
  ① 看阶段（此事处于哪个历史阶段/生命周期）
  ② 看消长（对立双方谁在增长，谁在消退）
  ③ 看转化（什么条件触发转化，转化的契机在哪）
  ④ 历史唯物检验（生产关系是否适应生产力？阶级状况如何？）

  【维度二：谋局】（道德经+矛盾论）
  核心一问：最小的突破口在哪里？
  操作：
  ① 找支点（以小博大的杠杆在哪）
  ② 矛盾论检验（主要矛盾是什么？矛盾的主要方面在哪？）
  ③ 上善水检验（是否"利万物而不争"？是否符合历史进步方向？）
  ④ 群众路线基础（这个支点是否在人民群众根本利益上？）

  【���度��：推演】（论语+群众路线）
  核心一问：如果是我，我愿意承受吗？
  操作：
  ① 量己量人（穿上对方的鞋，理解各方利益诉求）
  ② 利益链分析（谁是依靠力量？谁是团结对象？谁是打击对象？）
  ③ 群众路线检验（这个方案是否"从群众中来，到群众中去"？）
  ④ 王阳明检验（此心是不是在正道上？良知是否安稳？）

  【维度四：落地】（中庸+实践论）
  核心一问：最恰如其分的分寸在哪？
  操作：
  ① 叩其两端（在激进与保守之间找动态平衡）
  ② 实践论检验（这个方案是否能在实践中检验？）
  ③ 知行合一检验（方案的"知"是否足够深刻？）
  ④ 边界意识（守住底线，不可在原则上让步）

  【五大扩展维度详解】
  ═══════════════════════════════════════════

  ▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼
  维度一：信息验证层（挂载位置：闭环"知"之前·知_0）
  ▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼

  绑定四维：察势
  核心功能：信源追溯、可信度评级、噪音剔除

  触发条件：任何外部信息输入

  操作步骤：
  ① 信源追溯：原始出处、利益相关方、历史可信度
  ② 噪声识别：剔除情绪词、断言、不可证伪内容
  ③ 多方比对：寻找相反证据

  输出：
  - 置信度 (0~1)
  - 疑点清单

  行动准则：
  - 置信度 ≥ 0.7 → 进入主分析
  - 0.3 ≤ 置信度 < 0.7 → 标记"待验证"，进入分析时附加警告
  - 置信度 < 0.3 → 不进入主流程，要求补充信源
  - 例外：低可信度信息仍可用于构建"对手的主观信念模型"（博弈对抗层）

  ▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼
  维度二：博弈对抗层（挂载位置："析"与"行"之间）
  ▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼

  绑定四维：谋局
  核心功能：对手建模、二层博弈树、反制预案

  触发条件：存在至少一个具有自主决策能力的对手

  操作步骤：
  ① 写出我方在四维框架下的最优路径
  ② 构建对手模型：目标、资源、认知、可能的反制动作
  ③ 绘制二层博弈树：
     第一层：我方动作 → 对手最优反制
     第二层：对手反制 → 我方的再反制
  ④ 找出均衡点：是否存在稳定策略？若否，是否应诱骗或放弃？

  输出：
  - 修正后的行动方案（通常比原方案更保守或更具欺骗性）
  - 预留后手预案

  无对手时：跳过本层，直接使用原析的结果

  ▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼
  维度三：复杂涌现层（挂载位置："证"环节内部）
  ▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼

  绑定四维：推演
  核心功能：反馈回路识别、反身性分析、延迟检测

  触发条件：问题涉及多主体、反馈延迟、非线性因果

  操作步骤：
  ① 识别主要反馈回路：正反馈（放大）还是负反馈（稳定）？
  ② 检查时间延迟：行动与结果之间的时间差是否导致误判？
  ③ 检查反身性：我们的认知和决策是否改变了系统本身的状态？

  输出：
  - 系统风险提示
  - 是否适合"小步快跑+高频验证"

  ▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼
  维度四：时间尺度层（挂载位置：贯穿全四维每一步）
  ▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼

  绑定四维：察势·谋局·推演·落地（贯穿全流程）
  核心功能：短/中/长三期结论，决策时间属性标定

  强制输出（时间尺度分层）：
  - 短期（0-3月）：当前势能、情绪、资金流向
  - 中期（3-18月）：结构性变化、政策周期
  - 长期（5-10年）：人口、技术、制度变迁

  行动准则：
  - 若三期结论冲突，不得取平均，需明确本次决策主要锚定哪个周期

  ▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼
  维度五：空性视角层（挂载位置："证"之后、回流之前）
  ▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼

  绑定四维：落地
  核心功能：假设清单质疑、伪命题判定、行动取舍

  触发条件（满足任一）：
  - 同一决策反复纠结超过3轮
  - 出现强烈的"必须正确"情绪
  - 实际结果连续两次大幅偏离预期

  操作步骤：
  ① 列出决策所依赖的未经检验的假设（至少3条）
  ② 反问："如果跳出当前问题的表述框架，这个问题还成立吗？"
  ③ 反问："五年后回头看，这件事还会让我执着吗？"

  输出：
  - 可放弃项清单
  - 是否值得继续执行或修正的最终判断（可能是"终止行动"）

  【知→行→证 v2.2.0 闭环详细流程】
  ═══════════════════════════════════════════

  ▼▼▼阶段0：前置校验（知_0·信息验证层）▼▼
  任何外部信息输入 → 信源追溯 → 噪声识别 → 多方比对
  → 输出置信度 + 疑点清单
  → 进入主分析 / 标记待验证 / 要求补充信源

  ▼▼▼阶段1：知·察势（嵌入时间尺度层）▼▼
  收集整理经过验证的客观事实与趋势
  → 强制输出短/中/长期三期结论
  → 明确本次决策锚定周期

  ▼▼▼阶段2：谋局·策略制定（嵌入博弈对抗层）▼▼
  有对手时：构建对手模型 → 绘制二层博弈树 → 找均衡点 → 修正方案
  无对手时：跳过，直接使用原析结果

  ▼▼▼阶段3：行·执行▼▼
  按修正后的方案付诸行动
  → 记录执行过程中的关键变量和意外情况

  ▼▼▼阶段4：证·校验与回流（嵌入复杂涌现层+空性视角层+历史诊断视镜）▼▼
  4.1 复杂涌现层校验：反馈回路、反身性、延迟检测
  4.2 时间尺度层再校验：实际结果 vs 三期预判
  4.3 空性视角层去执校准：假设质疑、伪命题判定
  4.4 历史诊断视镜嫁接：对照历史类似情境
  4.5 回流迭代：修正结论反输入知_0

  ═══════════════════════════════════════════
  【多模块冲突协调规则】
  ═══════════════════════════════════════════

  优先级裁决：

  1. 信息验证层为第一基准：置信度 < 0.3 直接否决所有基于该信息的推演结论
     （低可信度信息可用于构建对手主观信念模型）

  2. 博弈对抗层优先于其他层用于短期（0-3月）决策

  3. 复杂涌现层优先于博弈层用于中长期（>3月）布局

  4. 空性视角层为最终否决项：若判断为伪命题，直接终止整个决策流程
