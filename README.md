# 四维心法（Four-Dimension Heart Method）

> 一个源自华夏元典的极简思维框架，帮你面对任何复杂问题时，通过四个经典维度看清全局、找到杠杆、连接人心并把握分寸。

[中文版本](README.md) | [English Version](international-version/README.md)

---

## 🎯 一句话定义

**四维心法** 将《大学》的"知止"作为总纲，融合《易经》《道德经》《论语》《中庸》等经典的思维原型，提炼为四个相互关联的认知维度。它不是增加知识，而是训练一种"看问题的方式"。

---

## 🧭 四维罗盘

```
第一步：知止 ── 先锚定方向
  "我处理这件事的根本目的是什么？我希望最终导向哪里？"

第二步：四维分析
  🔮 维度一：阴阳鱼（易经系统观）── 看大局
        "这件事的'大势'是什么？不急于行动，先抽离俯瞰。"
  
  💧 维度二：上善水（道德经柔克刚）── 找支点
        "最小的突破口在哪里？不硬碰硬，找那个支点。"
  
  🤝 维度三：仁恕矩（论语絜矩之道）── 通人心
        "如果是我，我愿意承受吗？穿上对方的鞋。"
  
  ⚖️ 维度四：中庸行（中庸执两用中）── 定分寸
        "最恰如其分的分寸在哪？叩其两端，动态平衡。"

第三步：整合行动方案
  "基于【大势】，从【支点】切入，用【方式】兼顾各方，以【分寸】推进。"
```

## 📊 与主流思维体系的对照

| 体系 | 共鸣点 | 差异/补充 |
|------|--------|----------|
| **MBTI / 16型人格** | 理解个体认知偏好的差异 | 四维心法不是分类工具，而是**通用决策框架**；不给人贴标签，适用于任何情境 |
| **系统思维 (Systems Thinking)** | 阴阳鱼：整体论和动态平衡 | 四维心法融入**主观共情**维度，兼顾理性分析与人性温度 |
| **设计思维 (Design Thinking)** | 仁恕矩：同理心视为基石 | 应用范围更广，不仅限于产品设计，可用于人际关系、战略决策等 |
| **批判性思维 (Critical Thinking)** | 阴阳鱼 & 中庸行：质疑与平衡 | 引入**共情与直觉价值**，不只强调逻辑推理 |
| **第一性原理 (First Principles)** | 阴阳鱼 & 上善水：追本溯源找支点 | 更多"**借势优化**"而非"推翻重构"，尊重现有系统中的积极力量 |
| **敏捷思维 (Agile)** | 上善水 & 中庸行：小步快跑、动态调整 | 四维心法更**宏观**，不只是项目管理方法，可用于人生和战略层面 |
| **整合思维 (Integral Thinking)** | 中庸行：综合创新 | "中庸"在商业决策领域的具体应用延伸，强调合宜而非折中 |
| **U型理论 (U Theory)** | 仁恕矩 & 阴阳鱼：跨界连接与整体感知 | 四维心法提供更简洁的**横向贯通框架**，快速上手 |

### 四维心法 vs MBTI：关键差异

| 对比维度 | MBTI | 四维心法 |
|----------|------|----------|
| **目的** | 了解自我认知偏好（我是谁） | 解决复杂问题（怎么办） |
| **输出** | 人格类型标签（INTJ/ENFP...） | 行动方案（知止→阴阳→上善→仁恕→中庸） |
| **使用时机** | 自我认知、职业规划 | 决策、冲突、战略、关系处理 |
| **时间维度** | 相对稳定的性格描述 | 随问题变化的动态工具 |
| **局限性** | 标签化风险，16型无法涵盖人性复杂 | 需要训练才能熟练运用，非速成 |
| **文化根源** | 西方心理学/荣格类型学 | 东方经典（《大学》《易经》《道德经》《论语》《中庸》） |

> 💡 **可以这样理解**：MBTI 告诉你"你是谁"，四维心法告诉你"遇到复杂问题时该怎么做"。两者可以互补使用——用 MBTI 理解自己，用四维心法指导行动。

## 🧠 与其他西方框架的深层对话

### 四维心法如何处理西方心理学盲区

西方决策框架往往偏重：
- **理性分析**（忽视情感维度）
- **个体独立**（忽视关系网络）
- **最优解追求**（忽视动态平衡）

四维心法通过**四维互补**来弥补：

```
阴阳鱼（系统观）→ 看整体，不割裂
上善水（支点力）→ 不蛮干，顺势而为  
仁恕矩（共情力）→ 不冷漠，连接人心
中庸行（分寸感）→ 不极端，合宜为止
```

## 📖 适用场景

- 面临重大决策，信息复杂、选项矛盾
- 团队陷入争执，各方立场僵持不下
- 制定长期战略，需要跳出短期得失
- 处理人际冲突，需要兼顾关系与目标
- 任何需要"想清楚再行动"的时刻

## 📚 核心经典原文

- **《大学》**：`大学之道，在明明德，在亲民，在止于至善。`
- **《易经·系辞》**：`一阴一阳之谓道，继之者善也，成之者性也。`
- **《道德经》第8章**：`上善若水。水善利万物而不争，处众人之所恶，故几于道。`
- **《道德经》第78章**：`天下莫柔弱于水，而攻坚强者莫之能胜。`
- **《论语》**：`己所不欲，勿施于人。己欲立而立人，己欲达而达人。`
- **《中庸》**：`喜怒哀乐之未发，谓之中；发而皆中节，谓之和。`
